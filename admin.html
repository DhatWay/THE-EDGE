Power Ratings
Fetches ESPN data for all in-season sports, computes team + coaching + defense matchup ratings, upserts to Supabase.
Idle.
Build Rosters
Reads team list from power_ratings, fetches every roster from ESPN, assigns per-player ratings, computes contributions. Rebuilds preserve enriched ratings when the player's position and starter status have not changed.
Idle.
Enrich Rosters
Reads current-season production from player_game_stats, z-scores per position group, refines ratings from the 50 baseline to a 40-95 scale.
Idle.
Build ATS & H2H
Builds team ATS form and head-to-head spread history from several seasons of results. Writes scores with every historical_odds row.
Idle.
Backfill Scores
Fills home_score and away_score on historical_odds rows that lack them. Matches by ESPN event id, which is the row's own game_id, with a ±1 day fetch window to cover the UTC/Eastern date shift. Resumable.
Idle.
Backfill & Calibration
Pulls multiple completed seasons per sport, rates each in order with carry-over, walks forward to measure projection error on unseen games, fits the model constants to real results, and measures how much the model adds beyond the closing line. Writes model_calibration.
Idle.
Build Trends
Mines historical results for repeatable situations. Rest and previous result reset at season boundaries. Writes the trends table.
Idle.
Pull Player Stats
Walks every completed game in historical_odds, pulls the ESPN box score, writes one row per player per game to player_game_stats. Writes are idempotent — a partial failure can be retried without duplicating.
Idle.
Build Prop Trends
Mines player_game_stats for per-player streaks against specific opponents. Pitcher strikeouts and batter strikeouts are separate lines.
Idle.
Refresh Injuries
Force-refresh the ESPN injury cache so the injury family reads the latest player status on the next pipeline run.
Idle.
Backfill Game ID Map
Bridges the two id systems. The Odds API's event id and ESPN's event id are unrelated strings; nothing joins across them until a row exists in game_id_map. This writes every link it can infer from historical_odds and line_history.
Idle.
Grade Shadow Picks
Reads ungraded shadow_picks, resolves each game_id to its ESPN id, loads the final score, writes W/L/P and P&L. History, Performance, and the learning loop all read the result column this fills.
Idle.
Grade Sim Bets
Reads pending sim bets from bet_log, resolves their ids through game_id_map, loads final scores, and writes the result back. Updates the local sim bankroll ledger.
Idle.
